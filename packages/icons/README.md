# @mszczygiel-projects/ui-core-icons

The icons of UI Core Library: one constant per icon, holding its `<svg>` element as a string. A bundler keeps only the icons you import. The `ui-core-icons` CLI builds a package with the same exports from your own SVG files.

The documentation site shows how to use it: [Getting started](https://mszczygiel-projects.github.io/ui-core-library/?path=/docs/guides-getting-started--docs), [Custom tokens and icons](https://mszczygiel-projects.github.io/ui-core-library/?path=/docs/guides-custom-tokens-and-icons--docs) and [Icons](https://mszczygiel-projects.github.io/ui-core-library/?path=/docs/foundations-icons--docs).
