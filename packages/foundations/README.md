# @mszczygiel-projects/ui-core-foundations

The design tokens of UI Core Library, built from the variables of its Figma Foundations file:

| Export           | What it is                |
| ---------------- | ------------------------- |
| `tokens.css`     | CSS custom properties     |
| `tailwind.css`   | a Tailwind 4 theme        |
| `typography.css` | text style classes        |
| `tokens.json`    | a manifest of every token |
| `.`              | typed references          |

The package also ships the `ui-core-foundations` CLI, which builds the same files from your own Figma export.

The documentation site shows how to use it: [Getting started](https://mszczygiel-projects.github.io/ui-core-library/?path=/docs/guides-getting-started--docs), [Configuration](https://mszczygiel-projects.github.io/ui-core-library/?path=/docs/guides-configuration--docs), [Custom tokens and icons](https://mszczygiel-projects.github.io/ui-core-library/?path=/docs/guides-custom-tokens-and-icons--docs) and [Foundations](https://mszczygiel-projects.github.io/ui-core-library/?path=/docs/foundations-overview--docs).
