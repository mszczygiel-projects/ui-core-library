# @mszczygiel-projects/ui-core-foundations

The design tokens of UI Core Library, built from the variables of its Figma Foundations file:

| Export           | What it is                |
| ---------------- | ------------------------- |
| `tokens.css`     | CSS custom properties     |
| `tailwind.css`   | a Tailwind 4 theme        |
| `typography.css` | text style classes        |
| `tokens.json`    | a manifest of every token |
| `.`              | typed references          |

The package also ships the `ui-core-foundations` CLI, which builds the same files from your own Figma export.

The Storybook site documents how to use the package: Guides/Getting started, Guides/Custom tokens and icons, and the Foundations pages.
