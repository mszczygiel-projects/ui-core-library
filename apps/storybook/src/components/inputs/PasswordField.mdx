# PasswordField

<ComponentOverview name="PasswordField" />

## Usage

Use PasswordField for a password or another secret a user types. Set `autoComplete` to `current-password` on a sign-in form and to `new-password` where the user chooses one, so that password managers fill it. Use TextField for anything a user may see as they type.

## Anatomy

The **base** holds the **label**, **control** and **hint**, as in TextField. Inside control, **input-row** holds the native **input** and the **reveal** button, whose **reveal-icon** shows the current state. The web component exposes these parts; React uses `.ui-password-field__<part>` classes. In Figma, each variant holds an exposed TextField: set its properties there, and `revealed` on PasswordField.

## Variants & tone

<FrameworkCanvas react={ReactStories.Variants} webComponents={WebComponentStories.Variants} />

`outline` is the default, `filled` adds a filled surface and `underlined` keeps only the bottom border, as in TextField. There is no tone.

## Sizes & density

`small`, `medium` (the default) and `large` follow the sizes of TextField, and each follows the surrounding density.

## States

`state` is `default`, `error` or `success`, as in TextField. Error sets `aria-invalid` and the feedback colours; it does not create a native validation failure. Hover and press share the active styling, keyboard focus uses the focus roles, and disabled fields leave the tab order and submit nothing. Read-only fields stay focusable and submit their value.

The reveal button is disabled with the field and its fieldset. A read-only field can still show its password.

## Content & labels

Supply `label` and `hint` in the language of the page. The reveal button has one name whatever its state, `revealLabel` or `labels.passwordField.reveal` (Show password), and its pressed state says whether the password shows. Configure the label once with `configureUiCore`.

## Behaviour

<FrameworkCanvas react={ReactStories.Revealed} webComponents={WebComponentStories.Revealed} />

- The reveal button toggles the input between `password` and `text`, keeps its focus and reports the new state: `ui-revealed-change` with `detail.value` in the web component, `onRevealedChange(revealed, details)` in React.
- The web component takes its initial visibility from the `revealed` attribute; its property holds the current state. React offers `defaultRevealed`, or `revealed` with `onRevealedChange`.
- Submitting the owning form hides the password again and reports it, so that a password manager reads the field as a password. A reset restores the initial visibility and value without an event.
- The value, the form entry, the validity (`required`, `minLength`, `maxLength`, `pattern`) and Enter follow TextField. The browser never saves the password to restore it later.

## Accessibility

- **Pattern.** A native password input with a [toggle button](https://www.w3.org/WAI/ARIA/apg/patterns/button/) after it: `aria-pressed` carries the state, and its name stays the same, so a screen reader says Show password, pressed.
- **Keys.** Tab moves from the input to the button. Space and Enter on the button toggle the visibility. Enter in the input follows the form rules of TextField.
- **Target.** The button keeps the icon size of the field and a pointer target of at least 24 by 24 pixels.
- **Preferences.** Forced colours keep the button visible and its focus indicator; the label motion follows reduced motion.

## Surfaces & themes

The field follows Light and Dark and the default, subtle, inverse and primary surfaces with the `control` family, as TextField does. The button takes the icon colour of the field and a tint on hover and press.

React's className, style and data-\* attributes reach the root; its ref, id, ARIA and native attributes reach the input. The web component uses the attributes `revealed`, `reveal-label`, `label-placement`, `min-length`, `max-length`, `auto-complete` and `readonly`, and passes the native `inputmode`, `enterkeyhint` and `spellcheck` of its host to the input.

## Tokens

<ComponentTokens component="control" />

PasswordField uses the `control` family of TextField, plus `color/control/action/background/active` and `control/action/target/min-size` for its button.

## Implementation notes

- Both implementations share the anatomy and the stylesheet of the text fields with TextField. The web component also shares the controller of the value and the form, with the browser's restore turned off.
- React listens to the `submit` and `reset` events of the owning form of its input to hide the password again.
