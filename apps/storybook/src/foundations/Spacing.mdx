# Spacing

## Layout

The layout roles space whole regions: the padding of a page, the gaps between its blocks and the width of its container. Some of them grow on wide screens, from the breakpoint on.

[View](?path=/story/foundations-spacing--layout)

The spacing inside components follows the density instead; see [Density](?path=/docs/foundations-density--docs).
