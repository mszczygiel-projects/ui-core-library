# Shadows

## Composite shadows

Ready-made shadows, a shape with a colour, as in Tailwind: `box-shadow: var(--shadow-md)`. Their colours are primitives, so they look the same in both themes.

[View shadows](?path=/story/foundations-shadows--composites)

## Roles

The shadow roles name what a shadow is for: the elevation of a layer, the state of an interactive element, an inset. They hold the shape only. Add one of the shadow colours of [Colors](?path=/docs/foundations-colors--docs), which follow the theme:

```css
.popover {
  box-shadow: var(--shadow-elevation-2) var(--color-shadow-default);
}
```

[View shadow roles](?path=/story/foundations-shadows--roles)

## Component shadows

The components below combine separate shape and colour tokens. Set either token on the component to customise its shadow in React or in a web component. The colours default to `--color-shadow-default` in Light and Dark.

| Surface                                       | Shape token                 | Colour token                      |
| --------------------------------------------- | --------------------------- | --------------------------------- |
| SelectField and Combobox popups, Listbox base | `--listbox-popup-shadow`    | `--color-listbox-popup-shadow`    |
| Menu popup, including in SplitButton          | `--menu-popup-shadow`       | `--color-menu-popup-shadow`       |
| DateField and DateTimeField panels            | `--date-field-panel-shadow` | `--color-date-field-panel-shadow` |
| Popover panel                                 | `--popover-shadow`          | `--color-popover-shadow`          |
